## Resumen 
Este repositorio esta enfocado en almacenar todas las notas de la clase de biopython del programa educativo de la Licenciatura en Ciencias genómicas de la UNAM en su semestre número 3, el curso se enfoca en la compresión y utilización del lenguaje de programación python para su aplicación en el manejo de datos biológicos, específicamente genómicos. 

Este objetivo se consigue mediante la enseñanza y utilización de paqueterías de python propias del manejo de datos como pandas ![pandas](https://img.shields.io/badge/pandas-2.3.3-%23690B7A?style=plastic&logo=pandas) , [biopython](https://biopython.org) , [seaborn](https://seaborn.pydata.org) , [matplotlib](https://matplotlib.org), entre otros. 

Con ellos se llevo acabo desde el procesamiento de secuencias genómicas hasta las bases para un análisis de expresión diferencial (DEA) y la presentación de sus resultados.

## Contenidos 

- [results](./results/) Directorio para guardar los resultados de los análisis y las representaciones, ahí se encuentran plots exploratorios para DEA y resultados de diversas indoles

- [src](./src/) Directorio que alamacena todo el source code:
  - [Ejercicios](./src/Ejercicios_clases/) : ejercicios de programación realizados en clase, generalmente en formato `.ipynb`
  - [Scripts](./src/Scripts_prueba/) : Scripts utilizados para realizar de manera automatizada o semi automatizada diversos análisis englobados en los `.ipynb`
  - [Notas](./src/notas_clase) : Notebooks `.ipynb` de las notas de clase con los códigos ejecutables para saber como funciona una paquetería utilizada en clase.
